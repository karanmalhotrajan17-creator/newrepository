What is Microsoft Fabric?

A unified analytics platform for working with data.

One Platform for Data Analytics

Microsoft Fabric brings multiple data and analytics capabilities together into one integrated environment.

Instead of managing separate systems for data ingestion, engineering, warehousing, data science and reporting, Fabric provides a connected experience.

At the center of Fabric is OneLake, which provides a unified logical data lake for the organization.

  • ✓ Data integration
  • ✓ Data engineering
  • ✓ Data warehousing
  • ✓ Data science

How Data Flows Through Fabric

Example of a typical analytics pipeline.

1. Collect Data comes from databases, applications, files and APIs.
2. Store Data is stored in Fabric's OneLake environment.
3. Transform Data is cleaned, transformed and prepared.
4. Analyze Power BI and other workloads analyze the data.

Step-by-Step Microsoft Fabric Tutorial

Follow these steps to understand a basic Fabric workflow.

1 Create a Fabric Workspace
+

A workspace is a collaborative area where Fabric items such as lakehouses, pipelines, notebooks, warehouses and reports can be created.

Start by creating or selecting a workspace in Microsoft Fabric.

2 Connect Your Data
+

Fabric can connect to many different sources, including databases, files, cloud services and APIs.

SQL Server → Fabric Data Factory Excel → Lakehouse REST API → Pipeline CSV → OneLake
3 Create a Lakehouse
+

A lakehouse combines capabilities commonly associated with data lakes and data warehouses.

You can use a lakehouse to store files and tables and then process them using Fabric tools.

4 Build a Data Pipeline
+

Create a Data Factory pipeline to automate the movement and processing of data.

Source ↓ Copy Data ↓ Lakehouse ↓ Transform ↓ Destination
5 Transform the Data
+

Remove duplicate records, handle missing values, change data types and create calculated columns.

Raw Data ↓ Clean Data ↓ Business Rules ↓ Analytics Data
6 Create a Semantic Model
+

A semantic model provides a business-friendly structure for analyzing data.

Tables, relationships, measures and business calculations can be organized for reporting.

7 Create a Power BI Report
+

Connect Power BI to the semantic model and create interactive reports and dashboards.

Data ↓ Semantic Model ↓ Power BI ↓ Dashboard ↓ Business Decision
8 Schedule and Monitor
+

Once your pipeline is working, it can be scheduled to run automatically so that reports receive updated data.

Monitor pipeline runs and investigate failures when they occur.

Frequently Asked Questions

What is Microsoft Fabric?
Microsoft Fabric is an integrated analytics platform that brings together data integration, engineering, warehousing, data science, real-time analytics and Power BI capabilities.
What is OneLake?
OneLake is the unified logical data lake associated with Microsoft Fabric. It provides a common data foundation for Fabric workloads.
What is a Lakehouse?
A Fabric lakehouse provides a data storage and analytics environment combining concepts from data lakes and data warehouses.
Can Fabric work with SQL databases?
Yes. Fabric provides capabilities for connecting to and working with SQL-based data sources.
Is Power BI part of Microsoft Fabric?
Yes. Power BI is one of the major workloads integrated into Microsoft Fabric.
